# 분리 전 Windows 업로더 계획

2026-10-18 저장소 분리 직전 계획의 보관본이다. 이 디렉토리는 비활성 이력이며 기존 리뷰의 맥락을 보존한다.
같은 저장소 배치, 경로 필터, 작업 수와 과거 검증 결과는 당시 상태이며 현재 구현 지시가 아니다.
기능을 구현 완료하거나 OpenSpec 아카이브한 기록도 아니다.

현재 계획과 작업 소유권은 [분리 안내](../../repository-split.md)를 따른다.
일부 설명 문구를 정리했으며 당시 기술 요구사항·작업·리뷰 결과는 유지한다. 분리 시점의 원본 바이트 대조 결과와 현재 편집된 문구를 구분한다. 이번 분리는 새 보안 리뷰나 Windows 실행 검증을 뜻하지 않는다.
